# Bookshop Billing System

## Project Description
The **Online Billing System** is a Java-based web application designed to streamline sales transactions and administrative management for retail businesses. It provides functionalities for cashiers to process bills efficiently while enabling managers to maintain customer, product, supplier, and user information seamlessly.

---

## Technologies Used
- **Programming Language:** Java  
- **Web Technologies:** JSP, Servlet  
- **Database:** MySQL  

---

## Features / Functionalities

### Cashier Module
- Search and manage customer details.
- Add products to a virtual shopping cart.
- Calculate totals with discounts and taxes.
- Print bills or invoices.

### Admin / Manager Dashboard
- **Customer Management:** Add, edit, and delete customer information.
- **User Management:** Create, update, and manage user accounts.
- **Product Management:** Manage product details including prices and stock.
- **Supplier Management:** Maintain supplier details and inventory sources.
- **Bill History:** View and manage all past transactions.
